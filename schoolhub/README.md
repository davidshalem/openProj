# SchoolHub – מערכת לניהול בית ספר

פרויקט Flask קטן ולימודי שמדגים את המסלול:

**משתמש → בקשה → Flask → לוגיקה/נתונים → Jinja → HTML → משתמש**

הפרויקט משתמש בנתונים בזיכרון בלבד. אין מסד נתונים, הרשמה או התחברות, ולכן קל להריץ אותו ולהסביר כל שורה.

## 1. דרישות מוקדמות

- Python 3.10 ומעלה
- `pip`

## 2. התקנה

פתחו Terminal בתוך התיקייה `schoolhub` והריצו:

```bash
python -m pip install -r requirements.txt
```

מומלץ בפרויקט אמיתי ליצור קודם סביבה וירטואלית, אך לשיעור קצר אפשר גם בלי.

## 3. הרצה

```bash
python app.py
```

לאחר מכן פתחו בדפדפן: <http://127.0.0.1:5000>

האפליקציה רצה עם `debug=True`, לכן שמירת שינוי בקוד תפעיל אותה מחדש. הוספות ושינויי ציונים נשמרים בזיכרון בלבד ונמחקים לאחר הפעלה מחדש.

## בדיקות

```bash
python -m unittest discover -s tests -v
```

הבדיקות בודקות את שלושת המסכים, חיפוש, הוספת תלמיד, שינוי ציון וחסימת ציונים לא חוקיים.

## 4. מבנה הפרויקט

```text
schoolhub/
├── app.py
├── data.py
├── requirements.txt
├── README.md
├── TEACHER_DEMO.md
├── static/
│   └── css/
│       └── style.css
├── templates/
│   ├── base.html
│   ├── dashboard.html
│   ├── students.html
│   └── grades.html
└── tests/
    └── test_app.py
```

## 5. מה עושה כל קובץ?

- `app.py` – שרת Flask: מקבל בקשות, מפעיל לוגיקה ושולח נתונים ל-Jinja.
- `data.py` – נתוני הדוגמה בזיכרון: תלמידים, ציונים, מורים, כיתות ומשימות.
- `templates/base.html` – השלד המשותף לכל המסכים: כותרת, ניווט, תוכן ו-footer.
- `templates/dashboard.html` – לוח הבקרה והכרטיסים הסטטיסטיים.
- `templates/students.html` – טבלת תלמידים, חיפוש וטופס הוספה.
- `templates/grades.html` – בחירת תלמיד, רשימת ציונים וטופס POST לעדכון ציון.
- `static/css/style.css` – העיצוב, הצבעים, הטבלאות וההתאמה למסכים קטנים.
- `tests/test_app.py` – בדיקות אוטומטיות פשוטות בעזרת כלי הבדיקות של Flask.
- `TEACHER_DEMO.md` – דף הצצה מפורט לשיעור בן כ-20 דקות.

## דרישות המערכת בקצרה

המשתמשים האפשריים הם צוות בית הספר, ובעיקר מורים ורכזים. המערכת מאפשרת לצפות בתמונת מצב, לחפש ולהוסיף תלמיד, לצפות בציונים ולעדכן ציון חוקי בטווח 0–100.

המימוש מכוון במכוון לפשטות לימודית. במערכת אמיתית היינו מוסיפים מסד נתונים, התחברות והרשאות, הגנת CSRF, ניהול שגיאות מלא ובדיקות נוספות.
